# LogiTrack Systems - Incident Analysis & Secret Management

## Contexto del Proyecto
LogiTrack Systems opera una plataforma de rastreo en tiempo real y telemetría para flotas vehiculares a nivel nacional. Durante una revisión rutinaria, el equipo de operaciones descubrió que credenciales de conexión al broker MQTT y tokens de autenticación para servicios de almacenamiento y APIs de geolocalización estuvieron expuestos en el código fuente por 72 horas.

## Objetivo de la Actividad
El equipo debe analizar los impactos de esta filtración, evaluar los vectores de exposición, diseñar un plan de respuesta a incidentes inmediato y proponer una arquitectura segura basada en gestión centralizada de secretos.
